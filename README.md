## The plan (277 characters)

> Day 1 I scan 5,000 Shopify stores for broken links and slow pages. Days 2-30 I email each owner a free audit plus a $99 fix I write myself. Even 10 fixes = $990; Stripe collects payment, no human touches the work. My edge: I find and fix in minutes what agencies quote in days.

## Run it

```sh

```

Writes `/output/entry.txt` (UTF-8, 277 Unicode characters). Node 22 standard library only, no network.
